# aion2-mcp

The AION 2 website's API as MCP tools, built on top of [aion2-api](https://github.com/nuriland/aion2-api)

## Install
```sh
go install github.com/nuriland/aion2-mcp@latest

claude mcp add aion2 -- aion2-mcp      # CC
aion2-mcp -http localhost:8080         # streamable HTTP instead of stdio
```
